# Laboratorium 4 - Express (Zadania 4.1 - 4.5)

## Uruchomienie

1. Zainstaluj zależności:
   ```bash
   npm install
   ```

2. Uruchom serwer developerski (nodemon):
   ```bash
   npm run dev
   ```
   lub standardowo:
   ```bash
   npm start
   ```

3. Serwer działa domyślnie pod adresem: `http://localhost:3000`
